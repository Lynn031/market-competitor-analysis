# 市场竞品分析 Skill · 使用说明

> 技能名：`market-competitor-analysis`  
> 定位：输入自家产品/品牌 + 目标市场，输出竞品对比、差异化定位与竞争策略建议。  
> 路径：零代码，纯结构化提示词驱动，可安装即用。

## 1. 安装方式

把整个 `market-competitor-analysis/` 文件夹放到 WorkBuddy 的技能目录即可：

- **用户级（推荐，全项目可用）**：`~/.workbuddy/skills/market-competitor-analysis/`
- **项目级**：`<你的项目>/.workbuddy/skills/market-competitor-analysis/`

放入后重启/刷新 WorkBuddy，技能即生效，对话中说出触发问法即可唤起。

## 2. 怎么用（4 步）

1. **唤起**：在对话里说一句触发问法，例如
   > "帮我做一份 便携咖啡机 的竞品分析，目标市场是中国"
2. **填输入**：技能会让你补全 `输入模板` 的三项必填（自家产品/品牌、品类行业、目标市场），其余可选。
3. **跑工作流**：技能按 7 步自动产出 5 个板块（格局速览 / 对比表 / 差异化定位 / 策略建议 / 待核实项）。
4. **收尾**：你核对"待人工核实项"，把需线下验证的数据补上，即可直接汇报。

## 3. 输入模板速查

```
自家产品/品牌 ：__________（必填）
品类 / 行业   ：__________（必填）
目标市场      ：__________（必填）
竞品名单      ：__________（选填）
分析维度      ：__________（选填）
分析深度      ：__________（选填：速览 / 标准 / 深度）
```

## 4. 输出结构（固定 5 板块）

1. 市场格局速览
2. 竞品对比表（Markdown 表格）
3. 差异化定位（优势 / 劣势 / 机会）
4. 竞争策略建议（动作 → 预期效果）
5. 待人工核实项

## 5. 红线提醒

- 不编造竞品数据；无来源标 `需人工核实`
- 数据缺失标 `未提供`
- 客观对比，不攻击竞品
- 真实企业信息先脱敏

## 6. 完整提示词在哪

可直接复制的 5 段式 Prompt 在 `SKILL.md` 的「五、完整 Prompt」一节。  
想改角色口吻、增删维度、调整输出板块，都从那里改起，改完重测 3 个案例即可。
